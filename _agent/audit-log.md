## Engine

| Decision / Ambiguity | Spec Section | Rationale | Resolution |
| :--- | :--- | :--- | :--- |
| **API Signature & Purity** | §2.3, Ground Rule 2 | Engine must be strictly pure with injected `{ now, rng, words }`. No I/O, no crypto, no DOM. | Define `reduce(state, action, ctx) -> { state, error?, alarmAt }`, `viewFor(state, playerId) -> RoomView`, and `nextAlarm(state) -> number \| null`. Injected `WordBank` interface defined in `@game/engine`. |
| **ELIMINATION Phase Flow** | §4, §4.1, §3.6 | Spec §4 includes a 6s `ELIMINATION` display before moving to `MRWHITE_GUESS` or next `DISCUSSION`. | When voting closes, transition to `ELIMINATION` with `endsAt = now + 6000`. On tick/timeout, proceed to `MRWHITE_GUESS` if voted out player is Mr. White, otherwise evaluate win check (leading to `GAME_OVER` or next `DISCUSSION`). |
| **Additive Types** | §3.5, §3.6, §3.7, §5 | `GameData` requires `lastElimination` (typed as `EliminationResult`) and word pair alias tracking (`civilianAliases?: string[]`). | Add optional properties to `GameData` in `@game/types` additively in a dedicated commit. |
| **Host Migration Timing** | §10.2 | Spec specifies 15s grace for host disconnects, but voluntary leave/kick leaves room without host. | Disconnection triggers 15s grace timer; reconnection cancels it. Explicit leave/kick triggers immediate reassignment to earliest-joined connected admitted player (alive preferred). |
| **Name Auto-Suffixing** | §8.3 | Duplicates get numeric suffixes (Sam, Sam 2). | Format as `${base} ${n}` ensuring total length <= 16 characters. |
| **Mr. White Guess Normalization** | §3.7 | Normalize words before comparison. | Lowercase, trim, collapse whitespace, strip diacritics/accents, strip punctuation, remove leading "the "/"a "/"an ", normalize simple plurals ('s'/'es'), check aliases, and allow Levenshtein distance <= 1 for words of 5+ letters. |
| **Effects & Reducer Output** | User Amendment 1 | Server needs structured effects for direct messages and connection closes. | `reduce` returns `{ state, error?, effects, alarmAt }` where `effects: EngineEffect[]` (`send` and `close`). `viewFor` remains a separate pure function. |
| **Purity & New ID Injection** | User Amendment 2 | Engine cannot generate UUIDs or hashes internally. | Injected `ctx.newId()` added to `EngineContext`. `hello` carries pre-hashed `tokenHash` computed by server; engine compares strings only. |
| **Per-Round Multi-Eliminations** | User Amendment 3 | A round can have both disconnect elimination(s) and a vote elimination. | `lastElimination` replaced/extended with `eliminations: EliminationRecord[]` list per round, tracking `{ id, role, reason, voteCounts }` plus `isTie`. |
| **Pause Deadlines vs Host Migration** | User Amendment 5 | Pausing freezes game phase timers only. Disconnected host must still trigger reassignment after 15s. | `paused` preserves `remainingMs` for phase `endsAt`, but `nextAlarm` continues checking `host.disconnectedAt + 15000` even while paused. |
| **Win Check Ordering** | Spec §3.6, User Note | Premature win checks can miss valid Mr. White guesses or compound round outcomes. | Win check runs strictly once per round, after all round eliminations (disconnects and votes) and after any Mr. White final guess. |
